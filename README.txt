Guerrilla Garage V2
==================
1. Extract ZIP. Upload the CONTENTS of this folder to the ROOT of a GitHub repository.
2. Repository Settings > Pages > Deploy from branch > main / (root) > Save.
3. Visit https://YOUR-USERNAME.github.io/REPO-NAME/ in Android Chrome.
4. Chrome menu > Install app or Add to Home screen.
5. After first online load, the app works offline. No notifications, accounts or server storage.
6. Export JSON backups regularly. Browser storage can be deleted by clearing site data.

IMPORTANT:
- Initial first-service cost is unknown, not assumed to be free.
- Refill #4 includes the user's additional ₹100, without adding fuel litres.
- Mileage is full-to-full and the fuel consumed is assigned to the preceding fill's fuel type.
- Trip costs are informational, not added to the total (avoids double-counting).
- Invoice photos are compressed and stored locally; many photos may exceed browser storage.
- Date-less historical entries are categorized as Undated in monthly reports.
- Due thresholds are editable; verify manufacturer intervals in owner's manual.
- PWA installation and offline caching require HTTPS or localhost.
